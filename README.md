# 하루

차분하게 오늘의 할 일을 정리하는 한국어 To-Do 웹앱입니다.

## 주요 기능

- 할 일 추가, 완료, 필터, 삭제
- 업무·개인·건강·공부 분류와 시간 설정
- 사용자별 Cloudflare D1 데이터 저장
- ChatGPT 로그인 기반 사용자 분리와 비공개 배포
- 모바일·데스크톱 반응형 화면

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

데이터베이스 스키마를 바꾼 뒤에는 `npm run db:generate`로 마이그레이션을
생성하고, `npm run build`로 배포 빌드를 확인합니다.

로컬 브라우저에서는 샘플 할 일로 미리보기 모드가 표시됩니다. AppDeploy에
비공개 배포하면 로그인 사용자 정보가 자동으로 전달되고 각 사용자의 할 일이
D1 데이터베이스에 따로 저장됩니다.
